# Crab Champions 비공식 한국어 패치

Crab Champions의 UI, 아이템·능력 설명과 런타임 HUD를 한국어로 표시하는 비공식 팬 패치입니다.

## 다운로드

[최신 패치 다운로드](../../releases/latest/download/Crab-Champions-Korean-v0.2.13.zip)

오른쪽의 **Releases**에서 `Crab-Champions-Korean-v0.2.13.zip`을 받을 수도 있습니다. GitHub가 자동으로 제공하는 `Source code.zip`은 설치용 한글패치가 아닙니다.

현재 패치 버전: **0.2.13**

배포 ZIP은 설치기, 번역 델타, 런타임 번역 파일만 포함하며 원본 게임 자산은 포함하지 않습니다.

## 지원 버전

- Steam Build ID: `20903826`
- 게임 업데이트로 Build ID가 달라지면 최신 한글패치가 필요할 수 있습니다.

## 설치 방법

1. Crab Champions를 완전히 종료합니다.
2. 다운로드한 ZIP을 완전히 압축 해제합니다.
3. `Crab-Champions-Korean-Patcher.exe`를 실행합니다.
4. `1: 설치`를 선택합니다.
5. 설치가 끝나면 Steam에서 게임을 실행합니다.

설치기는 Steam 라이브러리에서 게임 폴더를 자동으로 찾습니다.

이 설치기로 적용한 이전 버전이 있으면 상태를 확인해 자동으로 원복한 뒤 최신 버전을 설치합니다. 다른 모드와 원본 PAK는 건드리지 않으며, 같은 이름의 정체가 다른 파일은 안전 보관 폴더로 옮깁니다.

## 삭제 및 원복

1. 게임을 완전히 종료합니다.
2. 같은 설치기를 실행합니다.
3. `2: 원복`을 선택합니다.

한글패치가 설치한 PAK와 런타임 HUD 번역 파일을 제거하고, 네이티브 문구용 게임 실행 파일은 설치 전에 만든 검증된 백업으로 원복합니다. 사용자가 기존에 설치한 동일 버전의 UE4SS 파일과 다른 모드는 보존합니다.

## 번역 범위

- 게임 자산 내 플레이어 표시 문자열 1,315개
- 현재 및 구형 UI가 참조하는 한글 글꼴 6개 경로
- 네이티브 코드가 실행 중 생성하는 섬 종류·난이도 HUD와 상자·아이템 상호작용 문구
- 메뉴, 설정, 로비, 상점, 인벤토리, 전투 관련 UI 문구

정적 게임 자산에 없는 섬 종류·난이도와 상자·아이템·포털의 이름·고정 설명·동작 문구, 종료 확인 문장은 대상 UI에 한정된 런타임 번역으로 보정합니다. 로비와 난이도는 게임의 해당 UI 갱신이 끝난 같은 프레임에 번역하며, 동작 문구는 로비 액터의 상호작용 원문을 UI가 읽기 전에 번역합니다. 잠금 전 무기·능력·근접 무기와 인벤토리 제한 등 습득 불가 안내 12개는 게임의 네이티브 원문 자체를 한국어로 바꿔 한영 교대 표시를 제거하고 남는 고정 길이는 일반 공백으로 채웁니다. 다음 포털 선택창은 축복·도전 수정자·보상의 모든 이름과 설명 칸을 번역합니다. 포털 제목 `New Run`, `Holdout`, `Arcade`는 고유 모드명으로 영문을 유지하고 설명은 한국어로 표시합니다.

전투 중 목표 안내는 중앙 섬 설명과 오른쪽 목표 표시 모두 한국어로 표시합니다. 축복 4종과 도전 변형 24종의 이름·설명, 공세·보상 설명을 함께 처리하며, 런타임에서 수치나 강화 유형을 조합하는 문장도 완성된 문장을 같은 프레임에 번역합니다. 생물군계 이름은 `열대`, `북극`, `사막`, `화산`으로 번역합니다. `Island 4/9`, `Critical Chest`, `Arena` 같은 섬·포털·보상 제목은 영문 표기를 유지합니다.

## 알려진 제한 사항

- 게임 업데이트로 구조가 변경되면 최신 패치가 나올 때까지 설치가 중단될 수 있습니다.
- 설치 과정에서 임시 저장 공간 약 2GB가 필요합니다.
- Windows 또는 게임 자체의 실행 문제를 해결하는 패치는 아닙니다.
- 멀티플레이에서 서버나 다른 플레이어가 직접 보내는 문구는 번역되지 않을 수 있습니다.
- `DPS`는 고유명사로 취급해 표적 더미와 화면 HUD에서 영문으로 유지합니다.
- Holdout 포털 해골 위 3D 표지는 한글을 지원하지 않는 월드 글꼴을 사용하므로 `MINIGAMES` 영문 표기를 유지합니다. 포털 아이콘과 3D 표지는 숨기지 않습니다.
- GitHub의 `Source code.zip`이 아닌 Releases에 첨부된 패치 ZIP을 사용해야 합니다.

## 배포 방식

배포 ZIP에는 원본 게임 파일이 포함되지 않습니다. 설치기가 사용자의 정품 게임 PAK에서 필요한 자산을 추출하고 이진 차이를 적용해 한국어 패치 PAK를 로컬에서 생성합니다. 네이티브 습득 불가 문구도 원본 실행 파일의 해시를 확인하고 백업한 뒤 작은 이진 델타로 적용합니다.
